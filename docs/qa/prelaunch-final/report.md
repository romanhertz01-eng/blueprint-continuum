## Список дефектов

### D-1 (P1) — Горизонтальный overflow на row-макете, mobile
- **Где:** `/tools/chatgpt` (и, вероятно, другие row-инструменты: translate, ai-writer, ai-code, document-analysis, chat-подобные).
- **Симптом:** `document.scrollWidth = 487px` при `innerWidth = 390px`. Виновник: кнопка `h-10 px-5 rounded-lg font-semibold text-white` в панели действий (right = 487px).
- **Ожидание:** контент помещается в 390 без горизонтальной прокрутки.
- **Скрин:** `screens/mobile_chatgpt_probe.png`.
- **Не чинил** (только фиксация). Рекомендация: `flex-wrap` в панели кнопок row-макета или `w-full` для action-кнопки на sm.

### D-2 (P1) — На mobile в шапке нет бургер-меню
- **Где:** `/` при 390×844.
- **Симптом:** В шапке доступны только «Поиск» и «Переключить тему»; кнопки навигации/меню (`aria-label` содержащих «меню»/«menu») — **0 штук**. Мегаменю (`NavMegaMenu`) на десктопе не имеет мобильного эквивалента.
- **Скрин:** `screens/mobile_home_probe.png`.
- **Влияние:** мобильный гость не может дойти до `/pricing`, `/studios`, `/guides`, разделов /ai/* и tool-страниц через шапку — только через контентные ссылки.

### D-3 (P2) — Auth-gate на `/tools/ozhivit-foto` требует ручной верификации
- **Где:** `/tools/ozhivit-foto`.
- **Симптом:** автотест кликнул по чипу пресета «Раскрасить и оживить» — редирект не сработал (это ожидаемо для пресета). Кнопка «Генерировать» присутствует и, судя по единой реализации `AuthCTALink`, должна редиректить — но конкретный клик именно по ней в этом прогоне не выполнен.
- **Действие:** ручной клик по «Генерировать» перед запуском.

### Наблюдения (не дефекты)

- **Sitemap чист от draft.** Ни один из 13 draft-слагов не попал в `/sitemap.xml` — регистрация статусов через `status: 'draft'` в `toolPages.ts` работает.
- **`FAQ`-детектор** сработал на `/tools/*` за счёт наличия текста «вопрос»/«FAQ». На `/` FAQ секция есть, но детектор регекспом её здесь не идентифицировал — визуально `HomeFAQ` присутствует (см. `screens/01_home.png`).
- Мегаменю показывает 59–65 «ссылок» на таб — это включает шапку/футер/меню-контент вместе; уникальных внутренних адресатов (после дедупа) — 56.
